# Academia

Portal Next.js de Growith Business Academy (espacio de trabajo, implementaciones, reuniones y material).

## Desarrollo

```bash
pnpm install
cp .env.example .env   # opcional: GOOGLE_SCRIPT_URL
pnpm dev
```

## Datos

`getAcademiaPageData()` intenta `GOOGLE_SCRIPT_URL` y cae a `public/academia_page_data.json`.
